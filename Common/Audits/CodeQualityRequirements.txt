Report: Common/Reports/CodeQualityReport.pdf

1) Allaman style braces (same line braces allowed only for short single line statements) wherever language syntax allows.
2) Descriptive names, no short forms allowed.
3) Code follows SOLID to the extent required. As much SOLID compliant as possible without over engineering for existing complexity.
4) One entity (class/function) per file. 
5) No magic strings/numbers outside files generated by Common/Constants.
6) All classes must follow encapsulation and data hiding.
7) Enumerations must be preferred where there are choices and are benefitial.
8) As much of the styling as possible uses the theme variables and minimizes the use of hardcoded colors.
9) All classes are in pascal case
10) All global scope methods and all identifiers are in camel case (javascript only).
11) All global scope methods and all identifiers are in snake case (python).
12) All JS classes use default export (or spot instanciated).
13) All global JS methods use named export.
14) Shared data container classes without logic must utilize the Common/Scripts to share code across languages.
15) All attributes in html tags must be in kebab case.
