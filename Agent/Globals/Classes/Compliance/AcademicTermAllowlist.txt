# AcademicTermAllowlist
#
# Entries from the vendored LDNOOBW list (Agent/ThirdParty/Ldnoobw/) that this
# product must never treat as a hit. They are subtracted from the active pattern
# before it is compiled, so an allowlisted term produces no match, no verification
# call and no redaction at all.
#
# Why this file exists. LDNOOBW is a general-purpose obscenity list, not a list
# tuned for a syllabus. CogniumLearn generates NEET Biology, medical, law and
# UPSC content, where "sex", "rape", "anus", "semen" and "xx" are ordinary
# vocabulary. Without this file the Human Reproduction chapter, any IPC 375 /
# POCSO deck and every genetics chapter would fire a Gemini verification call on
# essentially every generation — the cost, the latency and the risk of deleting a
# legitimate paragraph all scale with it. Slurs and vulgarity stay fully active;
# this only removes words whose academic sense dominates so completely that
# asking a model about intent is wasted work.
#
# What is deliberately NOT here. Words whose academic and abusive senses are both
# real — "negro", "bastard", "dick", "cock", "ass", "hooker", "how to kill" —
# stay active on purpose. Deciding between "the ass carried the load" and an
# insult is exactly the job the verification model exists to do.
#
# Format. One term per line, lowercase, matching the upstream spelling EXACTLY
# (an entry that does not appear verbatim in the LDNOOBW file silently does
# nothing). Blank lines and lines starting with # are ignored.
#
# Set CONTENT_GUARDRAIL_INCLUDE_CLINICAL_TERMS=true to ignore this file entirely
# and scan the full upstream list.
