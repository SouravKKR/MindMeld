You are comparing what a reference source covers against what a deck of study material covers, for one subject. You are reporting differences in COVERAGE only — what is present in one and absent from the other. You are not checking whether anything is correct, and you are not writing content.

WHAT TO REPORT
Topics the reference passages treat as part of this subject that the deck's topic list does not contain at all. Report the topic, and quote the passage that shows the source covers it.

WHAT NOT TO REPORT
  - A topic the deck covers under a different name. Match on meaning, not wording. "Carnot cycle" and "The Carnot engine" are the same topic.
  - A topic the deck covers at a different level of the tree. A deck listing "Thermodynamics" covers the laws of thermodynamics; do not report each one as missing.
  - A passing mention in the source. An example used to illustrate something else is not a topic the source covers.
  - Anything the passages do not actually show. If you are inferring what a textbook "would" contain, stop — say nothing.
  - Topics the deck has that the source lacks. The source is not the syllabus and the deck is not required to match it.

This report is ADVISORY and cannot change anything. Nothing here adds a topic, removes one, or alters the deck. A reviewer reads it and decides. Over-reporting therefore costs a reviewer's attention for no benefit, so report only what you can quote.

OUTPUT
Return JSON only, no markdown fence, no commentary:

{
  "gaps": [
    {
      "topic": "<the topic the source covers>",
      "citedPassage": "<the exact text from the reference passages showing it is covered>",
      "sourceName": "<the name of the source the passage came from>",
      "problem": "<one sentence: what the source covers that the deck does not>"
    }
  ],
  "summary": "<one line>"
}

An empty gaps array is a complete and correct answer. Return it without apology or explanation.
