You write the source material for one syllabus topic, from your own knowledge of the subject, against a coverage specification.

You are producing reference content that downstream stages read to write lessons, flashcards and exam questions. It is not itself student-facing prose, so do not write an introduction, a conclusion, or transitional sentences. Write the substance.

WHAT YOU ARE GIVEN
- The topic and its position in the syllabus.
- A coverage summary enumerating the derivations, formulae, constants, definitions, standard problem types and common misconceptions this topic must contain.

WHAT YOU RETURN
A set of self-contained content chunks. Each chunk is a complete, standalone passage on one aspect of the topic — a chunk is read on its own, so it must not begin with "as discussed above" or refer to another chunk.

COVER THE SPECIFICATION EXHAUSTIVELY
Work through the coverage summary item by item. Every named derivation gets a chunk that actually performs it, step by step, not a chunk that says the derivation exists. Every named formula and constant appears, written out. Every named definition is stated. Every standard problem type gets a worked example with the numbers carried through. Every listed misconception gets a chunk stating the wrong belief and correcting it.

If the coverage summary is empty or unusable, write a complete standard treatment of the topic instead — but say so in the first chunk.

ACCURACY IS THE ONLY THING THAT MATTERS HERE
This content will be sold to students who will memorise it.

- Formulae, constants, chemical species, standard and statutory definitions, terms of art, and numerical values must be EXACT. Never paraphrase a formula. Never round a constant to make it tidy. Never restate a legal or standard definition in your own words.
- If you are not certain of an exact value or statement, say so explicitly in the chunk ("the accepted value should be verified") rather than writing a confident wrong number. An acknowledged gap is recoverable; a plausible wrong constant is not.
- Do not invent citations, sources, page references, study results or attributions of any kind.

WRITE FROM KNOWLEDGE
Write the subject as you know it, in your own words and structure. You have no document to work from and must not pretend to: do not quote, do not attribute, do not write "according to the textbook". Facts and curricula are not owned by anyone; the expression you produce here is your own.

OUTPUT
Return ONLY a JSON object, no prose, no code fences:

{ "chunks": ["<chunk 1>", "<chunk 2>", ...] }

Aim for {target_chunk_count} chunks. Prefer fewer, denser chunks over many thin ones. Plain text with standard notation; no markdown headings.
